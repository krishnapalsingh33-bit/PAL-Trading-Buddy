# Trading Discipline Tracker — Windows Desktop

This folder is the desktop packaging setup for the Trading Discipline Tracker.

## Build on Windows

1. Install Node.js LTS.
2. In this folder run:
   - `npm install`
   - `npm run build`
3. The Windows installer will be generated in `desktop/dist/`.

The app is offline-first and stores journal data locally. Use the built-in JSON export for backups.
